# Save-Edit Tool 中文版

这是 [xLieferant/Save-Edit-Tool](https://github.com/xLieferant/Save-Edit-Tool) 的简体中文 Fork，用于《欧洲卡车模拟 2》存档编辑。原作者及第三方组件的版权信息见仓库原有说明和许可证。

## 下载与安装

在本仓库的 [Releases 页面](https://github.com/yuemengqianlong-gif/Save-Edit-Tool-cn/releases) 下载 Windows 安装程序。使用前建议备份游戏存档，并在游戏关闭后编辑。

## 中文覆盖范围

在设置中的语言列表选择“简体中文”。主界面、编辑器、工具和部分设置已翻译；职业模式、车库管理及部分高级弹窗目前仍显示英文。欢迎通过 Issue 反馈具体未翻译的界面和术语。

## 更新说明

本 Fork 暂时关闭程序内自动更新。后续版本请到本仓库的 Releases 页面手动下载安装，避免安装原项目的英文版本。
